# Loops - 

## Loops in Python

Loops in Python are used to execute a block of code repeatedly until a condition is met or all elements of a sequence have been processed.

For example:
- Print numbers from 1 to 100.
- Iterate through a list of servers.
- Check the status of multiple Kubernetes pods.
- Process multiple files automatically.

**Python has two main types of loops:**
1. for loop
2. while loop
